## Changelog

All notable Poseidon product releases are documented in this file.

Poseidon deploys `main` continuously; a deployment is not itself a release.
A release is a deliberate, named `vX.Y.Z` checkpoint with a changelog entry,
described in `docs/VERSIONING_AND_RELEASES.md`. Entries below are generated
and reviewed via the Release Please workflow.
